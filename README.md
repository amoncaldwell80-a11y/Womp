# WOMP $WOMP Website

A one-page, responsive static website for WOMP $WOMP on Solana.

## Files
- `index.html` — page content
- `styles.css` — design and responsive layout
- `script.js` — contract-copy button and current year

## Important
The X/Twitter buttons currently point to `https://x.com/`.
Replace those links with the official WOMP X profile once you have created it.

The Pump.fun buttons use the WOMP contract address already supplied for this project.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. In the repository, open **Settings → Pages**.
4. Choose the branch/folder containing the site and save.
5. GitHub Pages will publish the site.

GitHub Pages can host static HTML/CSS/JavaScript directly from a repository.
